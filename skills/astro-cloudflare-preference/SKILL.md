# Preferência de stack web

Para projetos web novos, parta preferencialmente de Astro com Cloudflare Workers. Use React onde a interatividade justificar, D1 para dados relacionais, R2 para arquivos e KV para estado simples, conforme a necessidade do produto.

Trate essa stack como preferência, não obrigação. Se os requisitos indicarem uma alternativa mais adequada, explique brevemente o motivo. Preserve a stack de projetos existentes e respeite escolhas explícitas da pessoa responsável.
